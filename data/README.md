# Data

* `simulated_cohort.csv` – 40 simulated agents (20 RW, 20 Bayesian with free p), 400 trials each. Columns: `subject, trial, choice, reward, best_option, true_model`.
* `simulated_cohort_true_params.csv` – generating parameters for every simulated agent (ground truth; never seen by the fitting code).

Both files are regenerated by `python scripts/03_fit_compare_ppc.py --seed 2024`. No empirical data are bundled; see the main README for the CSV format to analyse your own data.
